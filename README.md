# 🎮 Luz Roja, Luz Verde – Juego del Calamar (React)

Mini juego web interactivo inspirado en la escena icónica de “El Juego del Calamar”.

El jugador compite contra oponentes simulados y debe pulsar **STOP** exactamente en el momento correcto para sobrevivir. Si se adelanta, se atrasa o es el último... 💀 eliminado.

## 🧩 Tecnologías utilizadas

- 🎨 **CSS** (animaciones, diseño responsive)

---

## 🧠 ¿Qué practico con este proyecto?

- Gestión de estado y eventos en React
- Lógica de juego basada en tiempo
- Animaciones y UX visual con CSS
- Estructuración de componentes
- Control de flujo e interacción del usuario
